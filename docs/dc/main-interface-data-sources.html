BLAST source capability matrix

Phytozome, lemna, and TAIR are the implemented main-interface BLAST targets. The program list is capability driven. Lemna may try its server first and fall back to matching release FASTA plus local BLAST+. Historical TAIR releases use their configured local assets only. Availability is a property of the chosen release; PHgo does not borrow a database from another release.

Species controls

A species key is internal identity while the visible label is the scientific/release name. Search filters candidates but does not change the selected release. CYP Custom assigns species in the row grid; Set all/Set remaining applies a chosen fallback. Rows in Custom mode may inherit the most recent earlier non-empty species, which is why the first active row must have an explicit species.

Decision checklist

Choose the source that owns the release you intend to cite. Set species before entering a large batch so every row has the correct context. For NCBI, first choose the Entrez database whose records contain the identifiers/fields you need. For CYP, decide whether species is per-row or applied to remaining rows.
