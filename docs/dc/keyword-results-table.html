Keyword Search Results Table

Read the table

Results are grouped by the input term and normally remain in input order. Use row checkboxes to choose records. The table can show source-specific columns; open row details to see the full schema, identifiers, attributes, provenance, and available FASTA without relying on a shortened cell display.

Columns and aliases

phgo_alias is the ranked alias list produced by the local Symbol Name database. Source alias, symbols, and synonyms remain source data and are retained in details and exports. Alias-like table cells display the first five values followed by an ellipsis when more are present; this is a display limit only.

Actions

Use filtering, sorting, group navigation, details, and selection commands shown on the page. Selected rows can be exported, moved to Canvas, or prepared as BLAST query sources when a sequence is available. Sequence preparation de-duplicates equivalent fetches and reports its progress; an unavailable sequence must be resolved or excluded before a sequence workflow can continue.

How to judge a row

  1. Confirm its group title matches the submitted term.
  2. Open View and verify source database, release/species, identifiers and description.
  3. Distinguish label_name from gene/protein/transcript identifiers.
  4. Check sequence availability before Canvas or BLAST transfer.
  5. Select only reviewed rows.

Internal fields

search_tern is the preserved legacy field spelling for the submitted term. geneid, protein_id, and transcript represent different biological identifiers. Extra provider fields remain in details/export even when not displayed.
