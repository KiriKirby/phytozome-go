Phylogenetic Trees

Platform and runtime boundary

System-tree computation is supported by the packaged Windows amd64 release. PHgo verifies mega-phgo-runtime.bin and its runtime-owned muscleWin64.bin beside the application. It does not search PATH, use an installed MEGA/MEGA-CC, or download a substitute. Macintosh and Linux report this feature as unsupported.

Input rules

The checked Canvas rows, in visible order, form the run. Protein mode requests protein alignment; DNA mode requires real nucleotide/CDS already embedded or resolvable from the row. PHgo never reverse-translates protein, guesses sequence kind from letters, pads residues, or repairs input. Immediately before runtime FASTA is written it removes one or more terminal * terminators; internal * characters remain visible to MEGA.

Alignment choices

TargetMethodsImportant controls
ProteinClustalW; MUSCLEClustalW exposes pairwise/multiple gap penalties, protein matrix, residue/hydrophilic penalties, gap separation, divergent cutoff, predefined gaps and guide tree. MUSCLE exposes gap open/extend, hydrophobicity multiplier, memory, iterations and clustering methods.
DNAClustalW (DNA); MUSCLE (DNA); ClustalW (Codons); MUSCLE (Codons)DNA methods expose their nucleotide penalties/matrix controls. Codon methods additionally require coding input and expose a genetic-code table; choosing a codon method does not make non-coding data valid.

Increasing a gap-opening penalty makes starting a gap less favorable; extension controls the cost of lengthening an existing gap. Keep Predefined Gaps preserves gaps already present in the input. Delay Divergent Cutoff postpones sequences above the chosen divergence threshold. MUSCLE Max Iterations trades running time for additional refinement; Max Memory is a runtime limit, not an image/export setting.

Tree methods and controls

Available methods are Neighbor-Joining, Minimum Evolution, UPGMA, Maximum Likelihood, and Maximum Parsimony. Test of Phylogeny enables bootstrap; Bootstrap Replicates is used only with bootstrap selected. Model/Method chooses the substitution-distance or likelihood model. Rates among sites, gamma settings, gap/missing-data deletion, and site-coverage cutoff determine which evidence reaches inference. ML additionally exposes search heuristic, initial-tree strategy/file, number of initial trees, branch-swap filter, and threads. MP exposes search method, random-addition initial trees, search level, and maximum retained trees.

Number of Threads defaults to one fewer than the logical CPUs, never below one, and cannot exceed the detected CPU count in the UI. More threads mainly affect runtime-backed parallel phases; it does not increase remote-network concurrency.

Refresh semantics

ChangeNext Refresh
Only display name or display-name sourceRender-only; alignment and tree are reused.
Selection, sequence, target, alignment method/parameter, tree method/parameterFull runtime compute and render.
Reactree-only view controls such as CoordImmediate viewer state; no PHgo refresh or recomputation.

The first refresh in a live Canvas and the first user refresh after opening a snapshot are full computations. Runtime error_text is shown before secondary missing-artifact errors. If MEGA identifies bad records, Skip unchecks the exact mapped Canvas rows and retries; PHgo does not silently switch alignment methods.

Recommended first tree

  1. Select at least two sequence-ready Canvas rows.
  2. Choose Protein unless you have real nucleotide/CDS for every selected row.
  3. Start with ClustalW or MUSCLE defaults and Neighbor-Joining.
  4. Refresh and inspect runtime errors before changing methods.
  5. Open Reactree, review labels/topology, then save PGO and export the desired viewer artifact.

Parameter rule

Every editable registered alignment/tree parameter is serialized into the runtime request. Read-only rows describe the selected MEGA path. A parameter irrelevant to the chosen method is not a hidden global switch.
