Using the Software on Macintosh and Linux

Install and start

Download the archive that matches your processor and operating system from GitHub Releases, extract it to a writable local folder, and start the supplied launcher from a terminal. Keep the executable, helper, and bundled files together. Put the folder on a disk with at least 50 GB free if you intend to keep the Symbol Name database or large local data caches.

Create a shell, dock, desktop, or application-menu shortcut using your desktop environment's normal mechanism. The shortcut should point to the launcher in the extracted folder, not to a copied executable with its companion files omitted.

Current platform boundary

Keyword search, supported downloads, result review, exports, sessions, and the non-system-tree workflows can run on supported Macintosh and Linux releases. The PHgo system-tree runtime is currently supported only by the packaged Windows amd64 release. On Macintosh and Linux the application reports that system-tree work is unavailable; it does not download a substitute runtime.

Using the complete Windows feature set

If you need the Windows-only tree workflow, run the Windows release through Wine where it is suitable for your environment. Follow the Wine User's Guide, create a dedicated prefix, install the complete Windows archive into that prefix, and keep all release files together. Wine is an external compatibility layer; its configuration, graphics drivers, and permissions are outside phytozome GO support.
