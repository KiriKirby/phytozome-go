Field, State, and File Glossary

Identity and provenance fields

TermMeaning
source_databaseThe connector that supplied the row, such as Phytozome, lemna, TAIR, NCBI, PLAZA, CYP, or imported FASTA.
species / genome / releaseThe biological organism and versioned dataset context. Similar labels do not make two releases interchangeable.
geneid / Gene locusA gene-level identifier or locus name. It is not automatically a protein accession.
transcriptA transcript/isoform identifier; one gene may have several.
protein_id / sequence IDThe translated protein or provider sequence record used for protein FASTA/BLAST.
gene_report_urlAn authentic row page explicitly supplied by input/provider—not a URL constructed from an identifier.

Naming fields

TermMeaning
label_nameThe selected short biological/display label for a result row.
labelname_typeHow that label was obtained: user choice, source field, or automatic Symbol Name ranking.
phgo_aliasRanked alias candidates returned by the local Symbol Name database.
alias / symbols / synonymsRaw provider metadata retained as evidence; not the same as PHgo's ranked list.
display_nameEditable Canvas/tree/MSA visible name. It can duplicate another row and is separate from the source label.
family_nameDerived Family BLAST review/export group name; it never overwrites hit label_name.

Coordinates and row states

A PHgo coordinate [item,row] is one-based visual Canvas identity. Tree runtime taxon IDs such as PHGOT000001 are stable internal mapping keys, not biological accessions. Green is selected, yellow is excluded through MSA Apply, and red is ordinarily unchecked. Filter flags mark suggested removal independently of whether the user later changes the checkbox.

BLAST evidence terms

identity is exact matches over the aligned region. query coverage is aligned query length divided by full query length. E-value estimates expected chance hits; lower is stronger. bitscore is a normalized alignment score; higher is stronger. target/query length ratio and target/UniProt canonical length ratio use different denominators and must not be interpreted as the same quality test.

File and artifact definitions

Extension/artifactMeaning
.fastaSequence records. Header detail depends on selected mode.
.xlsxFull structured exported result rows.
.pgoResumable PHgo workflow/session snapshot.
.pgvReactree viewer snapshot; it does not contain the complete Canvas workflow.
.nwkNewick tree structure.
input.fastaStable-ID FASTA handed to the MEGA runtime.
aligned.fastaRuntime-produced alignment shared with tree/MSA viewers.
runtime-request.jsonSelected methods and all editable runtime parameters.
runtime-response.jsonRuntime result, error text, artifacts, and reported skipped records.
viewer.payload.jsonNewick, alignment, record metadata and display mapping sent to viewers.
run.manifest.jsonFingerprints and artifact paths governing safe reuse.

Storage definitions

.cache/ is replaceable working data. output/ or a chosen export folder contains deliverables. A cache hit changes speed, not scientific meaning. ~ means an intentional empty PHgo FASTA/header field; it is not the literal biological value tilde.

How to use this glossary

When two columns look similar, compare the definition before filtering or exporting. Preserve the exact field name in reports, especially for gene, transcript, protein and length-ratio fields. Internal runtime taxon IDs and Canvas coordinates are mapping devices; cite biological identifiers from the source fields instead.
