Keyword Search Connector Documentation

Connector contract

Connectors isolate each provider's acquisition and parsing logic from the shared workflow. The result model records source database, release/species context, biological identifiers, structured metadata, and authentic row-level source URLs only when the source supplied them. The program does not manufacture a gene report URL from an identifier.

ConnectorDocumented source behavior
PhytozomeProvider-specific retrieval is isolated under the Phytozome source connector.
CYP/P450Downloads and verifies the independently published p450phgo.pgd, then performs species selection and keyword search entirely locally. Category prefixes a:, p:, f:, and b: restrict a query.
LemnaRelease download directories are authoritative for available releases and downloadable GFF3, AHRD, and FASTA assets.
TAIRVersioned workflows use only the selected release's configured official assets; a local miss is not replaced with another release.
NCBIUses the selected NCBI search type; eligible rows can use explicit Gene locus priority.
PLAZAUses public versioned FTP data for locus resolution and preserves plaza_* provenance fields.

Connector availability depends on each provider and network. Cache reuse and request coalescing reduce duplicate work but do not change a provider's access terms or rate limits.
