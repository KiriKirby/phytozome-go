Multiple Sequence Alignment

Open and synchronize the MSA

The browser-hosted JalviewJS MSA uses the aligned FASTA from the last successful Canvas refresh; both aligned FASTA and Newick must exist before it opens. Tree and MSA share the same selected rows. The left list always shows the PHgo coordinate before the raw display name and appends a display-only residues/alignment length percent value; those decorations are not part of the sequence name.

Save versus Apply

ActionEffect
SaveStores durable Jalview state—sequence edits, row states, groups, features, annotations, markers, settings and colours—for a later Canvas snapshot. It does not edit Canvas.
ApplySends permitted row/name/sequence changes back to Canvas, updates shared artifacts and selection state, and can therefore affect the next tree computation.
Export image...Writes a visual file only. It does not Apply, edit alignment data, or recompute the tree.

Image formats and dimensions

ControlDefaultMeaning
FormatSVGSVG is resolution-independent and best for later editing; PNG is raster; PDF embeds the same vector scene on a page sized from the logical scene.
Scale2xPNG-only raster multiplier: 1x, 2x, 5x, or 10x. It multiplies output pixels, not logical layout size, and is disabled for SVG/PDF.
Cell width / height9 / 13 logical pxPositive numbers controlling every residue cell. Width mainly changes horizontal density; height changes row spacing.
Column interval20Positive integer spacing for alignment-column labels when column numbering is enabled.

Content switches

  • Show PHgo coordinates (off): prefixes exported labels with the visible [item,row].
  • Show length ratio (off): adds non-gap/non-blank/non-terminal-marker residues over aligned row length.
  • Show length percent (off): adds the percentage form of that ratio.
  • Show alignment column numbers (on): draws MSA column numbering using Column interval.
  • Show right residue numbers (off): draws each row's cumulative ungapped residue endpoint at the right of each block. Advanced layout turns this on automatically.
  • Show groups and Show features (both on): include durable Jalview group/feature rendering when present.

Refresh preview rebuilds the preview after setting edits. Generate asks for the save target and writes the selected format. The default file base comes from the numbered payload/page title. The exporter creates a clean Jalview-native vector scene; it is not a screenshot and excludes checkboxes, selections, menus, scrollbars and window chrome.

Automatic layout

With Use advanced layout script off, every current exportable row and the full alignment width are rendered as one block. Use this for ordinary complete-alignment figures.

Advanced layout syntax

Each non-empty line is >rows\start,end[/allocation]. There are no comments, tokens cannot contain internal spaces, each line needs exactly one backslash, and parsing is case-sensitive.

>1,4/1,3/1,6\10,100/~,~,~
>~\100,200/50,50

The first line exports rows [1,4], [1,3], and [1,6] in exactly that order, takes boundary range [10,100) (90 alignment columns), and makes three 30-column blocks. Row coordinates are the one-based coordinates printed by PHgo. >~ means all current MSA rows and does not filter by green/yellow/red state.

Column boundary coordinates

Ranges use MSA boundaries, not one-based residue numbers: boundary 0 is before column 1 and boundary W is after the last column. Thus 10,100 means the half-open range [10,100) and contains 90 columns. In an endpoint, ~ means the open edge: ~,10 starts at 0, 10,~ ends at alignment width, and ~,~ selects all columns.

Block allocation

Counts after the slash split the chosen range from left to right. Fixed counts must be positive and sum exactly to the range length. An allocation ~ shares the remaining columns equally among all placeholders: 10,100/30,~,~ becomes 30,30,30. If the remainder is not evenly divisible, generation fails with the line number and failing token. Omitting allocation makes one block covering the whole range.

Common errors

  • Use 1,4, not [1,4], inside the script.
  • A row coordinate must exist in the current MSA payload and cannot repeat within one line.
  • Range endpoints must be between 0 and alignment width, with start strictly less than end.
  • ~ for all rows is valid only as the complete row side; do not mix it with explicit rows.
  • Multiple lines and their allocated blocks render top to bottom in input order.

Recommended editing cycle

  1. Open MSA after a successful tree refresh.
  2. Inspect names, gaps, groups, annotations and features.
  3. Use Save to persist browser/Jalview state without touching Canvas.
  4. Use Apply only when edits should return to Canvas and affect shared state.
  5. Use File → Export image... for a publication graphic.

Residue ratio definition

The displayed numerator counts characters that are not gap, blank, or terminal-marker characters. The denominator is the current aligned row length. It is visual metadata only and never becomes a FASTA name.
